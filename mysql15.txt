Queries and Sub-Queries
=========================
What is subquery?
--> A subquery is a query inside another query.
--> It is written inside parenthesis() and its result is used by the outer query.


it is also called as
--------------------
inner query
nested query
inner select 

purpose of subquery
-------------------
1.to break down complex problems into smaller queries
2.to use the result of one query as input to another to avoid multiple steps(write in a single query instead of temp tables).

general syntax
================ 
select column-list from table
where column operator(select column from table where condition);




===========================================================================================

TYPES OF SUBQUERIES IN SQL
===========================

A subquery is a query written inside another SQL query.

Types of subqueries:
1. Single Row Subquery
2. Multi Row Subquery
3. Nested Subquery
4. Correlated Subquery
5. EXISTS / NOT EXISTS Subquery


1. SINGLE ROW SUBQUERY
======================

A single row subquery returns exactly one row and one column, meaning it returns only one value.

It is generally used with single-row comparison operators:

=
>
>=
<
<=
!=
<>

Characteristics
---------------
1. Returns only one value.
2. Uses single-value comparison operators.
3. The subquery should normally return a single value when used with operators such as =, >, <, etc.
4. If the subquery returns multiple rows, it can cause an error.
5. If the subquery returns no rows, the result depends on the SQL expression and operator.

Syntax
------

SELECT columns
FROM table
WHERE column operator
      (SELECT column
       FROM table
       WHERE condition);

Example
-------

Find employees whose salary is greater than Rahul's salary.

SELECT emp_name, salary
FROM employees
WHERE salary > (
    SELECT salary
    FROM employees
    WHERE emp_name = 'Rahul'
);

How it works:
First the inner query executes:

SELECT salary
FROM employees
WHERE emp_name = 'Rahul';

Suppose Rahul's salary is 30000.

Then the outer query becomes:

SELECT emp_name, salary
FROM employees
WHERE salary > 30000;


2. MULTI ROW SUBQUERY
=====================

A multi-row subquery returns multiple rows and multiple values.

Because multiple values are returned, we commonly use:

IN
ANY
ALL


A. IN OPERATOR
==============

IN checks whether a value matches any value in the list returned by the subquery.

Syntax
------

SELECT columns
FROM table
WHERE column IN (
    SELECT column
    FROM table
    WHERE condition
);

Example
-------

Find employees who belong to departments where at least one employee earns more than 40000.

SELECT emp_name, dept_id
FROM employees
WHERE dept_id IN (
    SELECT dept_id
    FROM employees
    WHERE salary > 40000
);

Suppose the subquery returns:

20
30

Then the outer query effectively checks:

WHERE dept_id IN (20, 30);

Characteristics of IN
---------------------
1. Used when the subquery returns multiple values.
2. Checks whether the value exists in the returned list.
3. It is an easy alternative to multiple OR conditions.

Example:

WHERE dept_id IN (10, 20, 30);

is similar to:

WHERE dept_id = 10
   OR dept_id = 20
   OR dept_id = 30;


B. ANY OPERATOR
===============

ANY compares a value with each value returned by the subquery.

The condition becomes TRUE if it is satisfied for at least one value.

Syntax
------

SELECT columns
FROM table
WHERE column operator ANY (
    SELECT column
    FROM table
    WHERE condition
);

ANY can be used with operators such as:

>
>=
<
<=
=
<>

Example
-------

Find employees whose salary is greater than any salary in department 10.

SELECT emp_name, salary
FROM employees
WHERE salary > ANY (
    SELECT salary
    FROM employees
    WHERE dept_id = 10
);

Suppose department 10 has:

30000
35000
40000

The condition is:

salary > ANY (30000, 35000, 40000)

For > ANY, the salary only needs to be greater than at least one of those values.

For example:

32000 > 30000 -> TRUE

Easy meaning:

ANY = AT LEAST ONE


C. ALL OPERATOR
===============

ALL compares a value with every value returned by the subquery.

The condition must be TRUE for all values.

Syntax
------

SELECT columns
FROM table
WHERE column operator ALL (
    SELECT column
    FROM table
    WHERE condition
);

Example
-------

Find employees whose salary is greater than all salaries in department 10.

SELECT emp_name, salary
FROM employees
WHERE salary > ALL (
    SELECT salary
    FROM employees
    WHERE dept_id = 10
);

Suppose department 10 has:

30000
35000
40000

Then the employee's salary must be:

> 30000
AND
> 35000
AND
> 40000

So a salary of 45000 satisfies the condition.

Easy meaning:

ALL = EVERY ONE


IN vs ANY vs ALL
================

IN   -> Matches any value in the list.
ANY  -> Condition is TRUE for at least one value.
ALL  -> Condition is TRUE for every value.

Easy trick:

IN   -> Is it IN the list?
ANY  -> At least ONE
ALL  -> EVERY ONE


3. NESTED SUBQUERY
==================

A nested subquery is a subquery written inside another subquery.

In simple words:

Query inside a query inside another query.

Structure:

Outer Query
     |
   Subquery
     |
Nested Subquery

Syntax
------

SELECT columns
FROM table
WHERE column IN (
    SELECT column
    FROM table
    WHERE column IN (
        SELECT column
        FROM table
        WHERE condition
    )
);

Example
-------

SELECT emp_name
FROM employees
WHERE dept_id IN (
    SELECT dept_id
    FROM departments
    WHERE location_id IN (
        SELECT location_id
        FROM locations
        WHERE city = 'Hyderabad'
    )
);

How it works:

First the innermost query executes:

SELECT location_id
FROM locations
WHERE city = 'Hyderabad';

Then that result is used by the next query.

Then the result of that query is used by the outer query.

Characteristics
---------------
1. Contains multiple levels of queries.
2. One subquery is placed inside another subquery.
3. The innermost query generally executes first.
4. Can have multiple levels of nesting.


4. CORRELATED SUBQUERY
======================

A correlated subquery is a subquery that depends on the outer query.

The inner query refers to a column from the outer query.

Normal Subquery
---------------

Inner query
     |
executes independently
     |
Outer query

Correlated Subquery
-------------------

Outer query
     |
Inner query depends on outer row
     |
Next outer row
     |
Inner query executes again

Example
-------

Find employees whose salary is greater than the average salary of their own department.

SELECT e1.emp_name, e1.salary, e1.dept_id
FROM employees e1
WHERE e1.salary > (
    SELECT AVG(e2.salary)
    FROM employees e2
    WHERE e2.dept_id = e1.dept_id
);

Notice:

e2.dept_id = e1.dept_id

e1 comes from the outer query.

Therefore, the inner query depends on the outer query.

Characteristics
---------------
1. Depends on the outer query.
2. Uses a column from the outer query.
3. Usually executes logically for each row considered by the outer query.
4. Often uses table aliases to distinguish outer and inner references.

Easy definition:

A correlated subquery is a subquery that depends on the outer query.


5. EXISTS / NOT EXISTS SUBQUERY
===============================

EXISTS
-------

EXISTS checks whether the subquery returns at least one row.

It does not care about the actual value returned; it only checks whether a matching row exists.

Syntax
------

SELECT columns
FROM table
WHERE EXISTS (
    SELECT column
    FROM table
    WHERE condition
);

Example
-------

Find departments that have at least one employee.

SELECT d.dept_id, d.dept_name
FROM departments d
WHERE EXISTS (
    SELECT 1
    FROM employees e
    WHERE e.dept_id = d.dept_id
);

If a matching employee exists:

EXISTS -> TRUE

If no matching employee exists:

EXISTS -> FALSE

Why SELECT 1?

Inside EXISTS, we are only checking whether a row exists.

So SELECT 1 is commonly used because we do not need the actual column value.


NOT EXISTS
----------

NOT EXISTS checks whether the subquery returns no rows.

Example
-------

Find departments that do not have any employees.

SELECT d.dept_id, d.dept_name
FROM departments d
WHERE NOT EXISTS (
    SELECT 1
    FROM employees e
    WHERE e.dept_id = d.dept_id
);

If matching rows do not exist:

NOT EXISTS -> TRUE

If matching rows exist:

NOT EXISTS -> FALSE

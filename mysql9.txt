Numeric functions
--------------------
| Function            | Meaning                            | Example                        | Result       |
| ------------------- | ---------------------------------- | ------------------------------ | ------------ |
| `ABS()`             | Returns absolute value             | `SELECT ABS(-25);`             | `25`         |
| `CEIL()`            | Rounds **up** to nearest integer   | `SELECT CEIL(4.2);`            | `5`          |
| `FLOOR()`           | Rounds **down** to nearest integer | `SELECT FLOOR(4.8);`           | `4`          |
| `ROUND()`           | Rounds to specified decimal places | `SELECT ROUND(12.567, 2);`     | `12.57`      |
| `MOD()`             | Returns remainder                  | `SELECT MOD(10, 3);`           | `1`          |
| `POW()` / `POWER()` | Exponentiation                     | `SELECT POW(2, 3);`            | `8`          |
| `SQRT()`            | Returns square root                | `SELECT SQRT(25);`             | `5`          |
| `EXP()`             | Returns e raised to a power        | `SELECT EXP(1);`               | `2.718...`   |
| `RADIANS()`         | Converts degrees to radians        | `SELECT RADIANS(180);`         | `3.14159...` |
| `DEGREES()`         | Converts radians to degrees        | `SELECT DEGREES(PI());`        | `180`        |
| `SIGN()`            | Returns sign of a number           | `SELECT SIGN(-10);`            | `-1`         |
| `RAND()`            | Generates a random number          | `SELECT RAND();`               | `0–1`        |
| `GREATEST()`        | Finds maximum value                | `SELECT GREATEST(10, 25, 15);` | `25`         |
| `LEAST()`           | Finds minimum value                | `SELECT LEAST(10, 25, 15);`    | `10`         |
| `PI()`              | Returns value of π                 | `SELECT PI();`                 | `3.14159...` |
